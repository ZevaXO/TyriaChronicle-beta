## Install or update

1. Close Guild Wars 2.
2. Extract the downloaded ZIP.
3. Copy **TyriaChronicle.dll** into your GW2 **addons** folder, replacing the older copy when updating.
4. Start GW2 and enable **Tyria Chronicle** in Nexus.
5. Open it using the clock icon or **Ctrl+Shift+E**.

Your settings are retained when replacing the DLL. Version 0.2.1-beta enables Nexus update support. Install it manually once if you used 0.2.0-beta, then allow pre-release updates for Tyria Chronicle in Nexus. Nexus can then find newer beta DLLs here according to your update settings. Manual downloads remain available.

[Nexus information and download](https://raidcore.gg/gw2/nexus). Nexus is installed separately; this package does not include it and is not an official Nexus Library listing.

## Gw2Launcher / multiple accounts

Use the **addons folder that Nexus uses for the game instance you launch**. With localized execution this can be inside a numbered account folder, for example `Guild Wars 2/Gw2Launcher/1/addons`, rather than the main game's addons folder. Check your launcher configuration and that client's Nexus log; verify Tyria Chronicle appears under Installed in the relevant client.

Install in each separate active addon directory where you want the addon. Some launcher setups share or link folders, so multiple visible addons folders do not necessarily mean separate installations or settings.

## Why try it?

- See the event, map and a short explanation together.
- Copy a waypoint directly from a reminder.
- Mark an event **Done today** to stop more reminders until daily reset.
- Create your own lists, or begin with a template for Obsidian armour, Aurene weapons, HoT materials or a daily meta round.
- Choose reminders by category or individual event.
- Check Dawn, Day, Dusk and Night with the fish-marked Fishing button, and enable optional fishing reminders for Tyria or Cantha / Castora.
- Share an event or an entire train using xx:MM chat times, with Copy and experimental Say.

## Beta limitations

Schedules are bundled data, not live map status. Estimated active windows are not guarantees. List templates are farming aids, not complete crafting recipes. Daily completion is per catalog event; Ley-Line Anomaly shares Done today across all three maps until daily reset. Completion is marked manually. No GW2 API key is needed. Updates are provided through Nexus using this public repository.
